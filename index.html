1. 使用了哪兩個 API？

• Tab 1 (HKO Live)： 香港天文台官方開放數據 API (rhrread)，免費且免密鑰。
• Tab 2 (OpenWeatherMap)： 國際第三方氣象 API (/data/2.5/weather)，需要填寫個人 API Key。

2. API Key 放在代碼的哪裡？

// 你的 API Key 填在這裡 (Where your key goes):
const API_KEY = "YOUR_API_KEY_HERE";

// 調取沙田 (Sha Tin) 實時天氣的 API 網址:

const res = await fetch(url);
const data = await res.json();
